# 第12章 多态性与虚函数——Notification Center 综合复习项目

同一个项目贯穿整章。

- V0_No_Virtual：非虚函数，基类指针按静态类型调用
- V1_Virtual_Function：加入 virtual / override
- V2_Base_Reference：基类引用统一分发
- V3_Override_Check：用 override 检查函数声明是否一致
- V4_Abstract_Interface：纯虚函数与抽象类
- V5_Virtual_Destructor：通过基类指针 delete 派生对象
- V6_Integrated_Notification_Center：Email / SMS / App / Voice 统一分发与释放
