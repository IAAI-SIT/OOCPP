# 智能银行账户系统

## 打开与运行

1. 使用 Visual Studio 打开 `BankAccountAISystem.sln`。本解决方案使用当前环境中的 v145 工具集；如使用 Visual Studio 2022，可在提示时重定目标到已安装的 v143 工具集。
2. 选择 `Debug | x64`，按 `Ctrl+F5` 运行。
3. 程序在当前工作目录中读写 `accounts.txt`。

## 教学边界

- 该项目用于《面向对象程序设计》的综合实践，不处理真实账户、个人信息或真实资金。
- 账户数据为课堂模拟数据，文件格式仅用于演示输入输出流。
- 学生须先完成类图、核心函数和一组测试，再使用 AI 开展代码审查与测试补充。

## 建议测试

1. 建立余额 1000 元的储蓄账户，取款 1001 元，应失败。
2. 建立余额 500 元、额度 2000 元的信用账户，取款 2400 元，应成功且余额为 -1900 元。
3. 对信用账户继续取款 601 元，应失败。
4. 尝试存入 0 或负数，应失败。
5. 保存后重新读取，核对账户类型、余额和信用额度。
