# 面向对象程序设计（C++）课程教学代码

本仓库用于共享《面向对象程序设计》课程的课堂教学示例代码，帮助同学们复习课堂知识、理解面向对象程序设计思想，并通过实际编程加深对 C++ 的掌握。

代码将随课程教学进度持续更新。

## 一、课程内容

本课程以 C++ 为主要编程语言，重点学习类与对象、封装、继承、多态等面向对象程序设计的基本概念与实现方法，培养程序设计、代码分析、调试和问题解决能力。

## 二、代码目录

| 目录 | 教学内容 |
|---|---|
| Chapter08_VS2022 | 第8章：类和对象 |
| Chapter09_VS2022 | 第9章：怎样使用类和对象 |
| Chapter10_VS2022 | 第10章：运算符重载 |
| Chapter11_VS2022 | 第11章：继承与派生 |
| Chapter12_Polymorphism | 第12章：多态性与虚函数 |
| Student_Classroom_Review_Project | 类与对象课堂综合复习项目 |

各章节代码相对独立，便于同学们按教学进度学习和实践。

后续章节及相关教学示例将陆续补充。

## 三、开发环境

- 编程语言：C++
- 开发工具：Microsoft Visual Studio 2026
- 操作系统：Windows
- 建议安装 Visual Studio 的“使用 C++ 的桌面开发”工作负载

部分工程最初使用 Visual Studio 2022 创建，已保留原有目录名称。使用不同版本的 Visual Studio 打开时，可能需要调整平台工具集或 Windows SDK 配置。

## 四、代码下载与运行

**1. 下载代码**

在 GitHub 仓库主页点击绿色的 `Code` 按钮，选择 `Download ZIP`，下载后解压到本地目录。

也可以使用 Git 克隆仓库，方便后续获取更新。

**2. 打开工程**

进入相应章节文件夹，使用 Visual Studio 打开解决方案文件（`.sln`）或相应项目文件（`.vcxproj`）。

**3. 编译运行**

根据需要选择启动项目，编译并运行程序，观察程序输出，结合课堂讲解理解代码的实现过程。

如果出现编译错误，请先检查开发环境、平台工具集及项目配置。

## 五、学习建议

1. **先理解，再运行**：阅读代码，分析类的设计、对象之间的关系以及程序的执行过程。
2. **先预测，再验证**：运行程序前尝试预测输出结果，再通过编译、调试验证自己的理解。
3. **主动修改与扩展**：尝试修改数据成员、成员函数或类之间的关系，观察程序行为的变化。
4. **合理使用 AI 工具**：可以使用 AI 辅助解释代码、分析错误和提出改进建议，但应独立判断并通过实际运行验证。

## 六、使用说明

- 本仓库代码主要用于课堂教学、复习和个人学习。
- 部分代码侧重展示特定知识点，不一定是完整的工程应用。
- 代码可能根据课堂教学需要进行调整和更新。
- 请独立完成课程要求的实验和作业，不要直接以教学示例代替个人作业。
