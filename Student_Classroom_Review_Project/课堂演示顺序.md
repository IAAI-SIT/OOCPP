# 45分钟课堂演示顺序

1. V1（3~10 min）：只看 Student；问“为什么 name/score 不 public？”
2. V2（10~17 min）：现场只改 `this->score`、`return *this`；取消 `const Student` 的 setScore 注释观察编译错误。
3. V3（17~21 min）：对象数组、对象指针、对象引用；先预测再运行。
4. V4（21~28 min）：动态数组；观察 `new Student[capacity]` 导致的构造调用与 `delete[]` 的析构顺序。
5. V5（28~35 min）：打印两个 `students` 地址；修改 c2 后再看 c1；画出“两根指针指向同一块内存”。
6. V6（35~40 min）：加入深拷贝；再次修改 c2，验证 c1 不变；快速带过 static / friend。
7. 40~45 min：知识地图 + 三个出口题。

## 三个出口题
- `Student b = a;` 与先 `Student b;` 再 `b = a;` 有什么不同？
- `const Student&` 为什么常用于函数参数？
- 一个类拥有动态内存资源时，默认复制为什么可能不安全？
