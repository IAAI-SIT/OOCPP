# 故意编译失败的练习

本目录不参加 solution 的正常生成。每次只将其中一个文件复制到临时控制台项目中，替换原 main.cpp，观察编译诊断后修复。不要把三个 main 一起加入同一个项目。

1. 01：对应PPT第28页。补上 const，使函数成为 `void show() const override {}`。
2. 02：对应第43页。不能直接创建 Shape；应定义实现 area() 的具体类并创建该具体类对象。
3. 03：对应第43页。将函数改为 `double area() const override { return 0; }` 可验证类型问题；实际面积实现参见 Ex10。

第35—37页的非虚析构反例会产生未定义行为，不作为自动运行项目。课堂可讨论其错误原因；正确析构顺序在 Ex08 中验证。
